# CKANInstaller
A Simple [CKAN](https://github.com/KSP-CKAN/CKAN) Installer

# What it Does?
It Automatically: 
- Installs the latest ckan.exe
- Create a bin and .desktop in the system
- Create ckan icon in the system icons

# Dependencies
- mono
- make
- sudo
- git
- gh (github cli) OR installs the ckan.exe manually and put it in the project's root

# Installing
```
$ git clone https://github.com/goveiajoao/CKANInstaller ~/.local/share/CKANInstaller
$ cd ~/.local/share/CKANInstaller
$ make install
```

# Uninstalling
```
$ cd ~/.local/share/CKANInstaller
$ make uninstall
```
